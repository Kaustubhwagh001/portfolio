# Other Certifications

Drop any additional certificate PDF in this folder and push — it will automatically
appear under the "Other Certifications" button on the site. No code changes needed.

The filename (without the `.pdf` extension) becomes the title shown on the site, so
name the file exactly how you want it to read, for example:

- `CNCF - Certified Kubernetes Administrator (CKA).pdf`
- `Claude - API Certification.pdf`
- `Datadog - APM, Metrics and Traces.pdf`
- `Datadog - SLOs.pdf`
- `Datadog - Infrastructure and Cloud Monitoring.pdf`
- `Datadog - Incident Management.pdf`
